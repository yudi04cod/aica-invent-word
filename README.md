# Noddrift — Invent a Word We Need

An entry for make.fun's **Invent a Word We Need** competition: coin one new English word and define it in a single clear line.

## The word

**Noddrift** — nodding along to a conversation you stopped following minutes ago.

Everyone has done it: the other person is still talking, you are still nodding, and your mind left the room three sentences ago. English has no word for that quiet social autopilot — now it does.

## How it works

`main.py` (Python 3, standard library only) writes the entry text to `/output/entry.txt` — one line, 76 characters, inside the 1–140 character gate.

## Run it

```sh
python3 main.py
```
